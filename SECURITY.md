# Security Policy

## Supported versions

Only the latest release receives security fixes.

## Reporting a vulnerability

Please do not report security issues through public GitHub issues.

Use GitHub's private vulnerability reporting instead: open the repository's **Security** tab and choose
**Report a vulnerability**. Include a description of the issue, steps to reproduce it, and the Swift version
and platform you observed it on. You'll receive an acknowledgement within a few days, and a fix or a
mitigation plan as soon as the report has been confirmed.
